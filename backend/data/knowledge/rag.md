# RAG
Description: Retrieval-augmented generation grounds an LLM with relevant external context.
Fundamentals: ingest documents, chunk text, embed chunks, retrieve, and generate.
Related concepts: embeddings, vector databases, prompt engineering, and evaluation.
Recommended learning topics: metadata filters, retrieval quality, citations, and chunk overlap.
Common interview topics: RAG pipeline, hallucination reduction, retrieval ranking, and evaluation.
