# Azure
Description: A cloud platform with services for compute, data, identity, and deployment.
Fundamentals: resource groups, Entra ID, virtual machines, storage, and networking.
Related concepts: Docker, Kubernetes, CI/CD, serverless, and cloud security.
Recommended learning topics: App Service, Azure Functions, IAM, monitoring, and deployment.
Common interview topics: resource groups, Entra ID, Functions, storage, and VNet.
