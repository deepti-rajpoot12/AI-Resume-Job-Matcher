# Kubernetes
Description: A platform for orchestrating and scaling containerized applications.
Fundamentals: pods, deployments, services, namespaces, config maps, and secrets.
Related concepts: Docker, CI/CD, cloud platforms, observability, and networking.
Recommended learning topics: deployments, ingress, Helm, health checks, and autoscaling.
Common interview topics: pod lifecycle, service types, deployments, and rolling updates.
