# Git
Description: A distributed version-control system for tracking and collaborating on code.
Fundamentals: commits, branches, merges, rebasing, remotes, and pull requests.
Related concepts: CI/CD, code review, release management, and collaboration.
Recommended learning topics: branch strategy, resolving conflicts, revert, and interactive rebase.
Common interview topics: merge versus rebase, reset versus revert, and pull request workflow.
