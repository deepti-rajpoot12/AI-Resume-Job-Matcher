# Java
Description: A statically typed language widely used for backend and enterprise systems.
Fundamentals: syntax, OOP, collections, exceptions, JVM, and concurrency.
Related concepts: Spring Boot, REST APIs, SQL, testing, and Maven or Gradle.
Recommended learning topics: streams, dependency injection, unit testing, and service design.
Common interview topics: OOP principles, collections, threads, JVM memory, and REST design.
