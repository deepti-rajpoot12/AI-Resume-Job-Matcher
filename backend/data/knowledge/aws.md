# AWS
Description: A cloud platform offering compute, storage, databases, and networking.
Fundamentals: IAM, EC2, S3, VPC, managed databases, and monitoring.
Related concepts: Docker, Kubernetes, CI/CD, serverless, and cloud security.
Recommended learning topics: least-privilege IAM, deployment, logging, and cost awareness.
Common interview topics: EC2 versus Lambda, S3, IAM, VPC, and scalability.
