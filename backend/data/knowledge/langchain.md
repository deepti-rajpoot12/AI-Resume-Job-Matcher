# LangChain
Description: A framework for composing LLM prompts, retrieval, and application workflows.
Fundamentals: prompts, loaders, retrievers, chains, and output parsers.
Related concepts: RAG, vector databases, agents, evaluation, and structured output.
Recommended learning topics: retrievers, document loaders, prompt templates, and tracing.
Common interview topics: chains versus agents, retrievers, memory, and framework trade-offs.
