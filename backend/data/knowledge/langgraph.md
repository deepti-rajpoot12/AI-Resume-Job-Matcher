# LangGraph
Description: A framework for modeling stateful, controllable LLM workflows as graphs.
Fundamentals: state, nodes, edges, checkpoints, and conditional routing.
Related concepts: LangChain, AI agents, tool use, RAG, and human review.
Recommended learning topics: state design, routing, persistence, and error recovery.
Common interview topics: graph workflows, state machines, checkpoints, and agent control.
